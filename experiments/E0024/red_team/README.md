# E0024 Red-Team Notes

1. **External methods do not inherit evidence.** UK Lotto pairwise-overlap gains are not SA PowerBall predictive evidence; E0024 tested the relevant K13 geometry directly.
2. **Primary objective controls the verdict.** Pure balance is better balanced but worse on exact 4+/5 K13 coverage. Do not redefine the objective after seeing this result.
3. **Machine labels must be external.** Never infer a machine, ball set, or regime from the winning numbers.
4. **Oracle-machine leakage.** A model that uses the target machine in replay is not deployable unless the same variable is knowable before ticket cutoff.
5. **Proper score before K13 anecdotes.** Main tau=8 gained four K13 winner coordinates but worsened Brier. That is not promotion evidence.
6. **Heavy-shrinkage Main result is discovery only.** The tau=64 five-target result was found after the outcomes existed. It is a hypothesis generator, not a frozen prospective victory.
7. **No Main-to-XTRA transfer.** XTRA machine conditioning is negative in E0024.
8. **Change-point multiple testing.** The split date was selected by scanning all eligible dates, so use the max-stat permutation p-value, not an uncorrected single-split test.
9. **Video pseudo-physics is forbidden.** Result animations or post-selection videos cannot be treated as measurements of pre-selection ball dynamics.
10. **788 is not proven globally optimal.** E0024 failed to improve it with randomized greedy/one-swap search. Coding theory proves only that 20 fully disjoint radius-1 centres are impossible (`A(13,6,5)=18`); it does not prove 788 is the global maximum-coverage value.
