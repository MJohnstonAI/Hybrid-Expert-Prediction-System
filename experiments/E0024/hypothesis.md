# E0024 — External Strategy Championship

## Question

Can externally motivated strategies improve HEPS Main/XTRA high-order matching without reusing anti-crowd or game-rule arbitrage ideas?

## Arms

1. **Balanced-overlap K13 portfolio search** — fixed K13, fixed 20-line budget, exact 4+/5 coverage accounting, with balance used only as a secondary objective.
2. **Machine non-exchangeability audit** — external machine labels only; never infer machine from numbers.
3. **Oracle-known-machine prequential model** — asks whether machine information would improve full-field Brier score or K13 capture if the exact machine were known before the target.
4. **Chronological change-point scan** — target-blind maximum split statistic with permutation correction.
5. **Physical-video feasibility gate** — only promote if archived videos expose actual physical motion and pre-outcome features, not merely a graphical representation of already-selected results.

## Data boundary

Mechanical Era only, 2026-06-02 onward. Main uses the canonical ledger. XTRA uses its canonical ledger plus the already quarantined E0022 replay supplement for 25 Aug, 28 Aug and 1 Sep; those three rows remain noncanonical.

## Machine metadata

Machine names are external covariates. Existing canonical Main metadata are used where available; later Main and XTRA labels are stored in `machine_metadata_supplement.jsonl` with source URLs and may not overwrite canonical history.

## Evidence integrity

- Balanced coverage is portfolio geometry, not prediction.
- Machine-conditioned results are **oracle-known-machine diagnostics** unless pre-ticket-cutoff machine availability is independently demonstrated.
- Change-point discovery after outcomes exist is retrospective and cannot be promoted directly.
- No result may increase K or line budget.
