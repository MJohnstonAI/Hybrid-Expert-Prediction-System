# REGIME_STATIONARITY_AUDIT — Decision

## Decision

**PARTIAL ACCEPT**

### Rejected

- Do not create a PowerBall regime boundary at 2026-06-22.
- Do not relabel rows on/after 2026-06-22 as an unconfirmed electronic regime.
- Do not use outcome differences around that date as evidence that a mechanism change occurred.

### Accepted and implemented

- Separate fixed game format from per-draw mechanism.
- Record machine/RNG identity independently when known.
- Make unknown mechanism explicit rather than guessed.
- Require physical/mechanical experts to disclose training-window method/machine composition.
- Add an advisory stationarity diagnostic with externally pre-specified boundaries only.

## Evidence classification

- Claim: `PowerBall switched mechanism on 2026-06-22` -> **REJECT**
- Claim: `HEPS needs to represent draw-method/machine heterogeneity separately from game format` -> **PROVISIONAL_SIGNAL as methodology concern, accepted as infrastructure**

The infrastructure change is defensive data engineering; it does not assert that machine identity or draw method provides a predictive edge.
