# HEPS Archive

Use this directory for material explicitly retired from active research workflows when moving it is useful and does not destroy historical links.

Do not mass-move or delete legacy `workspace/` and `outputs/` artifacts merely to make the repository look cleaner. Stable historical paths are evidence and may be referenced by experiments, issues, commits, or external AI sessions.

Archive decisions should preserve:

- original meaning;
- reason for retirement;
- replacement concept if any;
- links to failure/claim registries;
- provenance and dates.
