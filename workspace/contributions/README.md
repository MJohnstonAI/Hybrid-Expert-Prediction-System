# External Contributions Workspace — Historical / Discovery Material

This directory contains raw or lightly processed contributions from AI agents, humans, and earlier HEPS research sessions.

**Do not treat files here as current HEPS doctrine or predictive authority.**

Before using any proposal from this directory:

1. read `AGENTS.md`;
2. read `governance/current_method_doctrine.md`;
3. read `governance/methodology_deprecations.md`;
4. check `knowledge/claim_registry.jsonl` and `knowledge/failure_registry.jsonl`;
5. find the derivative/current experiment in `experiments/registry.csv`;
6. reproduce the proposal against the canonical ledger if its claim has not already been adjudicated.

Important current cautions:

- HLR, VVD, terminal digit and exact target coordinate are derived views of one sorted-slot transition; do not multiply them as independent evidence.
- Historical E0019 HLR×VVD and E0020 terminal×HLR×VVD combination rules are superseded/rejected for forward acquisition.
- Pure structural-null global mobility cannot select predictive candidates because every Main coordinate has IID global inclusion probability 0.1.
- Johnson/coverage geometry has zero candidate-discovery authority.
- Original JOS-HDR exact-line density claims under the uniform gap null are rejected.
- Physics metaphors do not create predictive evidence without a measurable independent information source.
- Post-hoc replay and external claimed performance receive no confirmatory credit merely because they look strong.

The purpose of preserving this directory is provenance and hypothesis history, not to make every old idea available for automatic reuse.

Use the current experiment packages and governance files for forward work.
