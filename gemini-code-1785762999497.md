## 1. Project Overview & Mission

The **Hybrid Expert Prediction System (HEPS)** is an open-source, neuro-symbolic multi-agent predictive framework engineered for non-stationary, bounded stochastic time-series sequences.

Rather than relying on a single deep learning model, HEPS orchestrates domain-specific **Sub-Experts** (statistical density models, harmonic step-delta engines, cross-game resonance trackers, and physical boundary attractors) using a dynamic **Gating Network (Router)** featuring temperature scaling, dynamic entropy load balancing, and conformal uncertainty damping.
